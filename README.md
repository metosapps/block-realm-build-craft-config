# Block Realm Build Craft Remote Config

Production remote configuration for the Huawei release of
`com.blockrealm.buildcraft.huawei`.

Ads are fail-closed. Keep `ads_enabled` set to `false` until the new AppGallery
listing is live. To activate monetization later, add new package-specific values
for all three Yandex placement IDs, commit them, and only then change
`ads_enabled` to `true`.

Never reuse placement IDs from another app or publisher account.
